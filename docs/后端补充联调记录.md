# 后端补充联调记录

## 已完成后端补充

- `GET /review/merchant/list`: 返回 `list/overview/ratingDistribution`，支持 `keyword/rating/replyStatus`。
- `GET /review/customer/list`: 支持用户端“我的评价”页面读取历史评价与商家回复。
- `POST /review/reply`: 兼容 `reviewId` 与 `reply` 字段别名，商家可修改既有回复。
- `POST /order/get`: 兼容 `usrId/userId` 参数别名，非管理员仍以 JWT 当前用户为准。
- `GET /ops/wallet/transactions`: 兼容 `type=all`，返回 `list/transactions/total/platformStats/typeDistribution`。
- `GET /ops/audit/list`: 兼容 `actionType=all`，返回 `list/auditLogs/total/stats`。

## 已完成前端适配

- 管理端钱包流水页改为直接消费后端业务 payload，并归一化 `relatedOrderId/remark/createdTime` 字段。
- 管理端审计页改为直接消费 `list/auditLogs/total/stats`。
- 商家评价页改为使用真实评价列表 payload，回复提交使用 `reviewId + replyContent`。
